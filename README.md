
# Knowledge Cards

A playful general knowledge game featuring interactive flashcards and multiple-choice quizzes.

## Features

- Two gameplay modes: Flashcards and Quick Quiz.
- Six knowledge categories.
- Three difficulty levels.
- 60 built-in questions.
- Randomized question order and quiz options.
- Score and streak tracking.
- Progress indicators.
- Session results and accuracy.
- Local statistics using LocalStorage.
- Procedural sound effects using Web Audio API.
- Responsive desktop and mobile interface.

## Technology

- HTML5
- CSS3
- Vanilla JavaScript (ES Modules)
- LocalStorage
- Web Audio API

## Data Storage

Game statistics and sound preferences are stored locally in the browser.

No account or backend is required.
